# Conformance Tests

This directory contains negative and near-miss fixture tests for each diagnostic code generated by the Vellum engine.

Each diagnostic code must have:
- At least one negative test case (will fail)
- At least one near-miss test case (will pass)

## Structure

```
conformance/
├── diagnostics/
│   ├── V001/              # Each diagnostic code
│   │   ├── negative/      # Must fail
│   │   └── near-miss/     # Must pass (edge case)
│   └── V002/
│       └── ...
├── prompt-contracts/      # Per-assistant prompt contract tests
│   ├── claude/
│   ├── kiro/
│   └── opencode/
└── README.md
```

## Purpose

Conformance tests prove:
1. Every diagnostic fire correctly on invalid input
2. Invalid diagnostics don't fire on valid input
3. Each assistant's prompt contract is honored
